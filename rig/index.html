What it does

Each instrument with its own rig.

01

Chains

  • One chain per instrument
  • Several instruments at once
  • Add blocks on any wire
  • Parallel splits
  • Insert for real pedals
  • Mid-chain inputs and outputs
  • Several outputs per chain
  • Latency per stage
02

Amps, pedals and effects

  • Amps, cabs and drives
  • 14 delays, 13 reverbs
  • 16 modulations
  • Your .nam and IR files
  • LV2 and VST3 plugins
  • Tempo-synced effects
  • Knobs live while you play
  • Vocal Rasp for voice
03

Presets and scenes

  • Search presets by name
  • 8 scenes per preset
  • MIDI per scene
  • 50-version history
  • Presets as text files
  • 5 factory presets
04

TONE3000 and your plugins

  • One-click TONE3000 install
  • TONE3000 updates
  • Plugin browser
  • Plugin editor
  • Build your own plugin
  • Modeling from captures
  • Plugin export
05

Drums, metronome and backing tracks

  • 75 grooves, 15 styles
  • One tempo, tap in
  • Metronome 30–300 BPM
  • Backing tracks
  • Speed, key, A–B loop
  • Groove switches preset
  • Pick the outputs
  • JoVee Ruler
  • Groove and track export
06

Looper and virtual DI

  • 8 loopers per chain
  • Dry loops, any tone
  • Speed and reverse
  • Waveform editor
  • Footswitch looper
  • Take library
  • Virtual DI
07

Tuner and analysis

  • Tuner per input
  • 63-band spectrum
  • Harmonics on the neck
  • Sustain and intonation
  • Tone Doctor
08

Mixer and meters

  • Input and output mixer
  • Fader per output
  • Chain, DI, looper faders
  • Meters per chain
09

Stage and control

  • Compact view
  • Full screen
  • MIDI Learn
  • 34 MIDI commands, Bluetooth
  • Phone remote
  • AI over MCP
10

Setup and settings

  • Setup wizard
  • Mono or stereo I/O
  • Classic, Neon, Rack
  • Nine languages
  • Your folders
  • Autosave
  • Shared settings
  • In-app updates
